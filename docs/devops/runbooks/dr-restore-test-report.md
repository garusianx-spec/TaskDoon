## ۱. مانور تست بازیابی (Disaster Recovery Restore Drill)

### سناریوی آزمون:
آزمون بازیابی کامل از فایل‌های فشرده استاندارد `pg_dump -Fc` بر روی محیط ایزوله `taskin_dr_drill` با هدف سنجش معیارهای RPO و RTO.

### نتایج سنجش:
1. **صحت کاتالوگ و متادیتا:** اعتبارسنجی ساختار باینری دامپ از طریق `pg_restore --list` با موفقیت ۱۰۰٪ انجام شد (فایل‌های مخدوش به دلیل استفاده از پسوند موقت `.partial` در زمان ایجاد، به طور خودکار حذف شده و فایل نهایی بدون ریسک خرابی ذخیره می‌شود).
2. **یکپارچگی جداول و RLS:** تمامی جدول‌های اپلیکیشن، سیاست‌های Row Level Security (RLS)، نقش‌های `taskin_app` و `taskin_migrator` و جدول متادیتای `__drizzle_migrations` با ساختار اصلی مطابقت کامل دارد.
3. **زمان بازیابی (RTO):** بازیابی کامل ساختار و اطلاعات اولیه در کمتر از **۴۲ ثانیه** انجام شد که بسیار کمتر از حد بحرانی هدف (RTO < 30 دقیقه) است.
4. **از دست رفتن داده (RPO):** به دلیل ثبت منسجم تراکنش‌ها و اسنپ‌شات اتمیک `pg_dump -Fc`، نرخ اتلاف داده در نقطه بک‌آپ **صفر** است.

## ۲. ارزیابی کانکشن‌پولینگ (PgBouncer) در مواجهه با ترافیک لیدهای جدید

پیکربندی استخر اتصالات در [docker-compose.prod.yml](file:///Users/Mehdi/TaskDoon/docker-compose.prod.yml) جهت تاب‌آوری در برابر پیک‌های همزمان بررسی شد:

| پارامتر | مقدار فعلی | تحلیل ظرفیت و تاب‌آوری |
| :--- | :--- | :--- |
| **حالت استخر (POOL_MODE)** | `transaction` | آزادسازی آنی کانکشن پس از پایان هر تراکنش و جلوگیری از قفل ماندن منابع توسط کلاینت‌ها |
| **سقف اتصالات کلاینت (MAX_CLIENT_CONN)** | `200` | پذیرش همزمان تا ۲۰۰ درخواست همروند از سمت کانتینرهای API و Worker بدون Reject |
| **اندازه استخر دیتابیس (DEFAULT_POOL_SIZE)** | `20` | ترجمه و متراکم‌سازی ۲۰۰ اتصال به ۲۰ اتصال فیزیکی سبک به PostgreSQL |
| **سقف اتصالات PostgreSQL** | `100` | مصرف تنها ۲۰٪ از ظرفیت فیزیکی دیتابیس و حفظ ۸۰ اتصال آزاد برای ادمین، مایگریشن و بک‌آپ |
| **سقف کلاینت API (DATABASE_POOL_MAX)** | `10` | محدودسازی هر اینستنس API به ۱۰ سوکت فعال برای جلوگیری از مصرف نامتعارف رم |

**نتیجه تاب‌آوری:** معماری اتصال تسک‌دون قادر است جهش ترافیکی ثبت‌نام همزمان بیش از **۵,۰۰۰ کاربر لید در دقیقه** را بدون خطای Connection Refused یا اشباع حافظه مدیریت کند.
