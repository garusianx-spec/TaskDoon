# TaskDoon — temporary visual review

This temporary branch contains only visual-review additions: 16 previously captured full-page screenshots and this index. It is based on remote `main`; no uncommitted application work is included. Do not merge this branch into a development or release branch.

- Desktop viewport: **1440px** wide.
- Mobile viewport: **390px** wide.
- The marketing pages were rendered from the development environment's published PostgreSQL CMS content, using the existing TaskDoon design system.
- Embedded product previews use the documented synthetic demo workspace. CMS views show the temporary development review identity and development test history, not private customer records.
- The screenshots were visually reviewed and scanned for credentials, tokens, email addresses and phone numbers. PNGs contain only image chunks; no credentials, cookies, session state, logs, database exports or configuration files are included.
- The temporary review administrator's privileges were revoked and its session signed out after capture.

Click **Desktop** or **Mobile** to open a full-page image on GitHub; use the image's raw/download control to inspect it at its original resolution.
